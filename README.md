# IngatTugas — Website Pengingat Tugas

## Deskripsi

**IngatTugas** adalah website pengingat tugas yang dirancang untuk membantu mahasiswa mengatur, mencatat, dan memantau tugas agar lebih terorganisir. Website ini memudahkan pengguna dalam mengelola tugas kuliah, kegiatan organisasi, maupun keperluan pribadi dalam satu halaman.

Dengan tampilan yang sederhana dan modern, pengguna dapat mencatat deadline, menentukan prioritas, serta memantau progres penyelesaian tugas sehingga aktivitas sehari-hari menjadi lebih teratur dan produktif.

## Fitur Utama

- **Tambah Tugas** — Menambahkan tugas baru dengan nama tugas, deskripsi, kategori, prioritas, tanggal deadline, dan waktu.
- **Edit Tugas** — Mengubah informasi tugas yang sudah dibuat.
- **Hapus Tugas** — Menghapus tugas yang tidak diperlukan.
- **Kategori Tugas** — Mengelompokkan tugas berdasarkan kategori Kuliah, Organisasi, dan Pribadi.
- **Prioritas Tugas** — Menentukan tingkat kepentingan tugas, yaitu Tinggi, Sedang, dan Rendah.
- **Pengingat Deadline** — Menampilkan informasi tenggat waktu agar pengguna dapat mengetahui tugas yang perlu segera diselesaikan.
- **Pencarian Tugas** — Memudahkan pengguna menemukan tugas berdasarkan kata kunci.
- **Filter Tugas** — Menampilkan tugas berdasarkan status, waktu pengerjaan, kategori, dan prioritas.
- **Status Penyelesaian** — Menandai tugas yang telah selesai.
- **Statistik dan Progress** — Menampilkan jumlah tugas aktif, deadline hari ini, jumlah tugas selesai, dan persentase progres.
- **Agenda** — Menampilkan beberapa tugas terdekat berdasarkan deadline.
- **Penyimpanan Lokal** — Menyimpan data tugas menggunakan `localStorage` pada browser.

## Teknologi yang Digunakan

- **HTML5** — Membuat struktur dan elemen halaman website.
- **CSS3** — Mengatur tampilan, warna, layout, animasi sederhana, dan responsivitas website.
- **JavaScript** — Mengatur interaksi pengguna, pengelolaan tugas, filter, pencarian, statistik, dan penyimpanan data.
- **GitHub** — Menyimpan kode sumber dan mengelola repository proyek.
- **GitHub Pages** — Memublikasikan website agar dapat diakses secara online.

## Cara Menjalankan Website

1. Clone atau download repository ini.
2. Pastikan file `index.html`, `style.css`, dan `app.js` berada dalam folder yang sama.
3. Buka file `index.html` menggunakan browser seperti Google Chrome.
4. Website siap digunakan untuk mencatat dan mengelola tugas.

Website juga dapat dipublikasikan menggunakan GitHub Pages agar dapat diakses melalui tautan online.

## Penyimpanan Data

Website menggunakan `localStorage` untuk menyimpan data tugas pada browser. Data tetap tersedia ketika halaman dibuka kembali pada browser dan perangkat yang sama, selama penyimpanan browser tidak dihapus.

Saat ini, data tugas belum menggunakan database atau sinkronisasi antarpengguna.

## Tujuan Pembuatan

Proyek ini dibuat untuk membantu mahasiswa mengelola tugas dan deadline dengan lebih mudah sekaligus menerapkan pengetahuan dasar pengembangan website menggunakan HTML, CSS, dan JavaScript.

Selain itu, proyek ini menjadi sarana pembelajaran dalam membangun website interaktif, mengelola data di browser, dan menggunakan GitHub untuk menyimpan serta memublikasikan kode sumber.
